## So: the maps' response (open)

With the real maps Iray's nose red is 2.05 x its flat value (forehead 1.17),
Octane's 1.69: the nose tip's texel is only slightly above the forehead's
(M03 Head maps at the tip vertex's UV: Diffuse 0.40 / 0.28 / 0.21 against
0.35 / 0.24 / 0.19, Translucency Color 0.65 / 0.52 / 0.45 against 0.61 / 0.48
0.42; F04 nose = forehead), yet Iray amplifies it more than the bake does.
Whole-face log-log slope Octane vs Iray (Faithful, gloss0) is 1.05 / 0.98 /
0.90, so it is not a global contrast error: the nose is where it shows.
Flat means in Octane also sit 23 % short in red on the forehead (the mean
of a map is not the map: Jensen), so the flat scenes cannot settle the
absolute response.

1.11) and `-flat-thi` (Translucency Color x1.07) tell which map Iray
amplifies; the Octane side is rendered (dump and both Looks).

No code change, nothing fitted.
