# 2026-11-04 — IES light profiles (#34)

Goal: DAZ lights' **Light Profile** (IES) and Iray Uber's **Emission
Profile** → Octane's emission `distribution`. Variant: enhanced-final.

## Scenes

Generated by `scripts/dev/make-option-scenes.py` (Calib-L-IES-*), the bare
floor seen from 5.2 m straight above (cubes and sphere hidden) except the
emissive plane's:

| scene | base | light | profile |
|---|---|---|---|
| Point | Calib-L-Point-5k | point, 2.5 m over the floor's middle, rotation 0 | DAZ's `light_profile_test.ies` |
| Point-Down | same | rotated X −90° (a spot's "down") | same |
| Asym-Down | same | rotated X −90° | `calib/ies/Orbis-Asym.ies` |
| Rect | Calib-L-Rect-50 | 50 × 50 cm rect facing down | DAZ's |
| Emit | Calib-L-Emit-cd | 50 × 50 cm emissive plane facing down, 5000 cd/m² | DAZ's, as Emission Profile |
| Emit-Asym | same | same | Orbis-Asym |

DAZ's test profile (in the app bundle, referenced by its absolute path) is
axially symmetric: 0 cd within 35° of its axis, ~230–820 cd from 36° to
160°, 0 again from 161° to 180°. Orbis-Asym is written for this: a
downlight to 60° (cos(1.5 θ)), × 1 / 0.6 / 0.1 / 0.3 at φ 0 / 90 / 180 /
270. The first version had 0.5 at both 90° and 270° and could not tell the
handedness — rewritten mid-session. DAZ's spot light has no Light Profile
channel (the generator's spot variant failed on it, dropped).

## What DAZ hands Iray (.mi)

- A point light with a profile: `dzpm_ies_light` with `flux` (5000),
  `scene_unit_size` and `profile` (a `lightprofile` block: the file, flags 2,
  hermite 1, resolution φ × θ); the same for the rect (its `rectangle` kept).
  `dzpm_ies_light` is NVIDIA's `ies_light`: `measured_edf` with the identity
  frame, intensity flux / `light_profile_power` → the profile's shape at the
  light's flux.
- `/Runtime/ORBIS/Orbis-Asym.ies` came out as the absolute file in My
  Library: DAZ resolves a file channel against the content directories.
- Uber: `emission_profile_enable` true, `emission_profile` the block;
  `emission_flux` unchanged (5000). The MDL divides by the profile's power.
- `mi-oracle.py` now inlines `lightprofile` blocks (file content-relative /
  `<daz>/…`, flags, hermite, resolution); fixtures compare file names.

## Octane

- Octane's own sample `hallway.orbx` has an IES on a blackbody emission's
  `distribution`: greyscale image (36), `filename` `assets/11.ies`,
  `iesPhotometryMode` 1, a Spherical projection (77) with `positionType` 3
  and rotation Y 270.
- Probe (pins of 77 / 36 / 53 / 54): `positionType` entries World space 1,
  Object space 3, Normal space (IES lights) 4 (default 3);
  `iesPhotometryMode` (attribute 415) default 1; the blackbody's
  `normalize` is about temperature, not the distribution.
- Orientation, Asym-Down (light local X = world X, Y = world −Z, Z = world
  up), object space:
  - rotation 0: the lobe went sideways to world +Z = local −Y → Octane's
    axis is −Y (Y-up, nadir down).
  - X +90°: the floor lit; X −90°: black → the transform maps the profile's
    sphere into the coordinate space.
  - X +90° with the second Orbis-Asym, 300 lm: brightest towards world +Z
    (φ 0), a narrow dark notch towards −Z (φ 180, the 0.1 between two
    linear ramps), world −X brighter than +X (0.6 v 0.3) → φ 0 = sphere +Z,
    φ 90 = sphere −X. Right-handed, like Iray's (+x, +y, +z).
  - The pole (θ = 0) shows a small bright dot: Orbis-Asym's θ = 0 row
    differs by φ (a synthetic file's fault; a real file has one value there).
- Power, the same 300 lm export without the profile as the reference
  (Octane's plain point light is calibrated against Iray), floor at
  θ = 30° (1.44 m from the middle), 13 × 13 px, PNG linearised with
  gamma 2.2:

  | φ | Octane IES / plain | Iray's I(ω) · 4π / ∫ I dΩ | ratio |
  |---|---|---|---|
  | 0 | 11.72 | 11.84 | 0.99 |
  | 90 | 7.12 | 7.10 | 1.00 |
  | 270 | 3.61 | 3.55 | 1.02 |
  | 180 | 1.25 | 1.18 | 1.06 |

  with the power × 1 / 0.0597 (`mean_share`: the profile's flux over 4π ×
  its peak). Octane doesn't renormalise the distribution; the 6 % at φ 180
  is the linear-in-φ dip (Octane's interpolation of the 0.1 row may differ).
- Export as built (no probe overrides), 200 samples: Point lights the floor
  broadly (axis forward, the dark cone off the floor); Point-Down a dark
  disc of ~0.89 m radius under the light — 19.6°, the file's 161–180° zero
  band, so the axis points **up** as Iray's frame says; Asym-Down black (the
  downlight shines at the ceiling); Rect the same ring with a squarish hole;
  Emit lights the cubes from the front; Emit-Asym only a dim floor (its
  axis horizontal, away from the camera, cut by the plane's front side).

## Process

- Passing `--dump` to `orbis export` for a modified copy of a scene *moves*
  the cached dump to the copy's name: the original needed a fresh
  `daz-dump.sh`. Copy the dump first.
- The orientation probes used a temporary environment override of the
  projection rotation, removed afterwards.
