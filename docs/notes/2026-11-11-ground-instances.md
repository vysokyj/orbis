# 2026-11-11 Auto ground and instances (#125)

Goal: does DAZ's auto Iray ground (Ground Position Mode Auto, #119) count
the copies of a DAZ instance node, and a hidden node that only serves as an
instance target? `usd::environment::ground_height` took the lowest y over
every exported mesh's own points: copies were left out, a hidden prototype
counted.

## Scenes
Generated by `scripts/dev/make-option-scenes.py` from Calib-Tone-Default
(Draw Ground on), the instance node taken from Calib-CastShadows-Off (as
`daz-build-node-flags.dsa` builds it):
- **Calib-Env-Mi-GroundAuto-Instance**: the sphere where it stands, its
  instance at x 120, y -60 (the sphere's origin is its bottom: the copy's
  lowest point is -60 cm, the floor at 0).
- **Calib-Env-Mi-GroundAuto-InstanceHidden**: the sphere hidden at y -60,
  its instance at the sphere's own place (y 15).

## .mi export (headless DAZ, no render)
| Scene | lowest drawn point | `environment_dome_ground_position` y |
|-------|--------------------|--------------------------------------|
| -Instance | -60 (the copy) | -0.001 |
| -InstanceHidden | 0 (floor) | -0.001 |

- DAZ's auto ground leaves the instance node's copy out: -0.001, not -60.001.
- In the `.mi` the copy is an `instance` of the same object, named
  `<object>_instance_1_<id>`, with `handle` = the instance node's label,
  listed **directly in the root instgroup**; a node's own geometry sits in
  its shape's `igroup`. `mi-oracle.py`'s `geometry_min_y` now skips the
  root group's direct members (the six older fixtures with the field keep
  their values: Calib-Strand -45, -Low -60, -LowHidden 0, ...).
- A hidden target: DAZ hands Iray **neither the node nor its instance's
  copy** (8 objects, no `SphereInstance`). ORBIS draws the copy (the
  "hidden source still serves its instances" rule from UltraScatter) -
  filed separately, see below.

## Rule
`ground_height` ignores instance copies (as before) and meshes kept only
as a hidden node's prototype (`Mesh::prototype_only`). No Iray render
needed: the ground height is what DAZ hands Iray, read from the `.mi`.
