# 2026-11-04 — Top Coat Bump (#61)

Goal: export Iray Uber's Top Coat Bump (and Top Coat Bump Mode) to the
Octane coat; check what the coat does with the base's bump.

## What DAZ and Iray do

- DAZ's Uber: `Top Coat Bump Mode` (enum 0 Height Map, 1 Normal Map) and
  `Top Coat Bump` (float 0 – 50, default 1, mappable, invalid without a
  map) in the Top Coat / Bump group (the shader presets' channel lists).
- `irayubermaterial.mdl`: the Top Coat gets
  `calc_mix_layer_normal(top_coat_bump, base_bump, base_bump2)` —
  the coat's bump blended with the base's (`add_detail_normal`,
  `base::blend_normals` at weights 1), else with `base_bump2`; **without
  a coat bump the base's bump** (or `base_bump2`, or both blended). So in
  Iray a coat over a bumped base is bumped too.
- New scene **Calib-CoatBump** (`make-calib-scenes.py`): a sharp clear coat
  (Fresnel IOR 1.5, roughness 0.05) over a matte red base, no gloss. Maps
  are ours, generated by the script: `calib-coatbump-dimples` (8 × 8 sine
  dimples) for the coat, `-ridges` (24 sine ridges in V) for the base,
  each also as the tangent-space normal map of that height (`-n`, steepest
  tilt 45°, OpenGL green up), `map_gamma` 1.

  | sphere | channels |
  |---|---|
  | B1 | coat only |
  | B2 | + base Bump Strength 1 (ridges) |
  | B3 | Top Coat Bump 1, height (dimples) |
  | B4 | Top Coat Bump 3, height |
  | B5 | Top Coat Bump 1, Mode 1 (dimples normal map) |
  | B6 | + base Normal Map 1 (ridges normal map) |
  | B7 | coat height + base height |
  | B8 | coat height + base normal map |

- DAZ's .mi (fixture `calib/references/mi/Calib-CoatBump.json`):
  height mode → `top_coat_bump = base::file_bump_texture(factor = Top Coat
  Bump)` (B4 factor 3; at 1 the default, left out), normal mode →
  `base::tangent_space_normal_texture`; `top_coat_bump_enable` true. The
  base's Bump Strength → `base_bump` as `file_bump_texture` (Calib-Mi-Maps
  P8 factor 0.6), its Normal Map → `base_bump` as
  `tangent_space_normal_texture` (named `base_normal_map` in the .mi),
  `base_bump_enable` true. `src/iray.rs` now emits these (both base maps
  at once: not yet seen, left out); all fixtures pass.

## Octane

Manual: Universal's Coating Bump / Coating Normal — without them the
coating uses the default shading normal. Render (enhanced-final, 400
samples, ~30 s) before the change: B2 and B6 showed the ridges in the
red base but the coat's reflections stayed smooth — the coat ignores the
base's bump, unlike Iray.

Export (`coat_bump_pins`): the coat's height map on the coat's bump pin
at Top Coat Bump as the image's `power`, else the base's Bump Strength
map at power 1 (as the base's own bump); the coat's normal map on the
normal pin, else the base's Normal Map. On Universal `coatingBump` /
`coatingNormal`; on the weighted coat's metal (Mode 1) and the anisotropic
coat's Specular Layer their `bump` / `normal`. Two height maps can't share
one pin: the coat's wins (B7).

High-frequency detail on each sphere (σ of the grey image minus its 3 px
Gaussian blur, rows 540 – 590, 60 px wide; the HDRI's reflections set a
floor):

| sphere | before | after |
|---|---|---|
| B1 smooth | 11.0 | 11.0 |
| B2 base bump | 10.9 | 14.2 |
| B3 coat height 1 | 10.4 | 9.9 |
| B4 coat height 3 | 10.5 | 12.2 |
| B5 coat normal | 8.3 | 15.1 |
| B6 base normal | 4.6 | 8.6 |
| B7 coat + base height | 3.9 | 3.9 |
| B8 coat height + base normal | 3.8 | 7.2 |

By eye: B2 / B6 / B8 now carry the ridges in the coat, B5 strong dimples,
B4 faint dimples, B3 and B7 nearly smooth — Octane's bump at power 1 of
the dimples (8 periods across the UV) is weak where the 45° normal map is
strong. B8 shows the ridges, not the coat's faint dimples: whether
Octane combines `coatingBump` with `coatingNormal` or the normal map
wins isn't visible at this strength.

## Against Iray (second session, same day)

Iray reference `calib/references/iray/Calib-CoatBump.png` (Iray Server,
5000 samples, 18c3a65). Octane enhanced-final, 800 samples, ~60 s a
render.

By eye, Octane as of 796cf3b: B5 / B6 / B8 (normal maps at 1) match;
B2 (base ridges) and B3 / B4 (coat dimples at 1 / 3) about half as bumpy
as Iray; **B7** (coat + base height) nearly smooth in Octane, while Iray
shows the base's ridges and the coat's dimples together — the coat's map
alone on `coatingBump` (at power 1) drowned the ridges.

The σ-of-high-pass metric from the first session doesn't rank bump
strength here: a stronger bump breaks the HDRI's reflections up and the
σ falls (B2 ×1 / ×4 / ×10: 9.8 / 7.0 / 5.9). So instead, the RMS of the
grey Octane image minus Iray's (both blurred 1 px), per sphere in a
disc of radius 34 px — the bump pattern lies in the same place in both,
so the right strength minimises it. Every height map's `power` scaled by
k in the exported `project.ocs` (`orbx_ocs get/set`):

| k | B1 | B2 base ridges | B3 coat 1 | B4 coat 3 | B5 | B6 | B7 | B8 |
|---|---|---|---|---|---|---|---|---|
| 1 | 0.90 | 7.69 | 7.18 | 14.67 | 1.15 | 1.07 | 7.23 | 1.52 |
| 2 | 0.80 | **2.88** | **5.42** | **9.21** | 1.17 | 1.07 | 6.80 | 1.08 |
| 3 | 0.80 | 8.13 | 6.12 | 12.13 | 1.19 | 1.06 | 7.63 | 1.01 |
| 4 | 0.76 | 10.82 | 6.77 | 13.15 | 1.20 | 1.07 | 8.32 | 1.41 |
| 6 | 0.77 | 12.15 | 8.53 | 16.08 | 1.13 | 1.14 | 10.02 | 2.99 |
| 10 | 0.85 | 13.17 | 11.36 | 17.73 | 1.19 | 1.08 | 8.30 | 5.16 |
| fix | 0.85 | 3.06 | 5.57 | 9.29 | 1.15 | 1.14 | **2.11** | 1.09 |

(B1, B5, B6: no height map, the noise floor ~1.) k = 2 wins on the
base's and the coat's maps alike, so one constant: `BUMP_POWER` 2 ×
Iray's factor (Bump Strength — before ignored, always 1 — and Top Coat
Bump). For B7 the coat pin now gets both height maps summed: a Mix
texture (38) at amount ½ of the coat's and the base's map, each at twice
its power ("fix" row: B7 7.2 → 2.1, and by eye the ridges and dimples of
Iray's B7).

Is it the map's resolution? Iray's `file_bump_texture` is native (only
the signature is in DAZ's `libneuray.so`; NVIDIA's docs say only
"degree of bumpiness"; MDL-SDK's stdmodule has no `base.mdl`).
- Octane: the dimples swapped for the same pattern at 2048 px
  (`orbx_ocs put`, new): B3 / B4 differ from the 512 px render by
  0.86 / 1.48 RMS, at the noise floor — Octane's bump is per UV, not per
  texel.
- Iray: if it took the slope per texel (factor × Δh per texel), factor
  1 / 3 on these dimples would tilt the coat 2.8° / 8.4°. As normal maps
  of exactly that tilt on B5's slot, they rendered visibly flatter than
  Iray's B3 / B4 — so not plain per-texel (a central difference over
  two texels would be ×2, which fits; unproven). Whether Iray's bump
  depends on the resolution needs an Iray render of a 2048 px copy: #75.
